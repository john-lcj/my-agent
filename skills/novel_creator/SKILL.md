# novel_creator —— 把一个念头,写成让人读得下去的小说

需要帮主人构思或续写小说、故事时,先读本指南,再动笔。核心:**先立骨架再填血肉,
冲突驱动情节,细节落地人物。** 不要一上来就堆华丽辞藻。

## 动笔前先定的五件事

1. **前提(一句话)**:谁,想要什么,被什么挡住。例:"一个失忆的钟表匠,要找回被偷走
   的最后一段记忆,而唯一的线索掌握在杀害他妻子的人手里。"
2. **主角与弧光**:他开篇是什么样的人,结尾变成什么样,中间靠什么逼他改变。人物 = 欲望 +
   缺陷 + 会做出的两难选择。
3. **核心冲突**:外部(对手/环境)与内部(主角的心结)各一条,二者最好互相纠缠。
4. **世界规则**:设定服务于冲突,只交代影响剧情的部分;切忌为设定而设定。
5. **基调与视角**:第几人称、悬疑/温情/荒诞……定下来后全程一致。

## 结构骨架(三幕,可伸缩)

- **第一幕·建置**:用一个"扰动事件"打破日常,抛出核心问题,让读者非追下去不可。
- **第二幕·对抗**:不断加码,主角的尝试一次次失败或代价更高;中点放一个反转或真相。
- **第三幕·收束**:最低谷 → 主角靠弧光里的成长做出关键抉择 → 解决核心冲突,呼应开篇。

## 写场景的要诀

- **每个场景都要有"目标—障碍—结果"**,结果最好让局势变糟或变复杂(否则这场可删)。
- **show, don't tell**:用动作、对话、细节让读者自己感受,别直接告诉"他很愤怒"。
- **对话承担三件事**:推进情节、暴露性格、埋伏线索;闲聊一律删。
- **进得晚、出得早**:场景从冲突临近时切入,目标达成或反转后立刻收。

## 文风与修订

- 先求清楚,再求好看;删掉不影响理解的形容词与副词。
- 名词具体、动词有力,胜过一堆华丽形容。
- 初稿只管写完;修订时再砍废话、强化冲突、统一节奏与视角。

## 自查

- [ ] 读者在第一页就知道"谁想要什么、为什么难"了吗?
- [ ] 每一场都推动了情节或揭示了人物吗?没有的删掉。
- [ ] 主角的转变是被剧情逼出来的,而非作者强行安排?
- [ ] 结尾回应了开篇抛出的核心问题吗?
