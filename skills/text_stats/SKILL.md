# text_stats

当用户想知道一段文本有多少字/字符/行/段/句,或大致需要读多久时使用。

中英文混排友好:中文按"字"计、英文按"词"计,并区分含/不含空白字符;
同时给出段落数、句子数与按 300 字·分(中)/ 200 词·分(英)估算的阅读时长。

输入参数:
- `text`(string):要统计的文本。

这是一个示例 skill,演示插件系统:把目录丢进 skills/ 即可被自动发现并加载,
无需改动主循环或治理层。
