# email_writing —— 写出清晰、得体、能推进事情的邮件

需要替主人起草或润色邮件时,先读本指南,再据此动笔。核心原则:**一封邮件只推进一件事,
让收件人 30 秒内知道"你要他做什么、什么时候、为什么"。**

## 通用结构

1. **主题行**:具体 + 可检索。写"3 月预算复核 — 需你周四前确认",不要写"关于预算"。
   如需对方动作,可前缀 `[需回复]` / `[仅周知]` / `[需审批]`。
2. **第一句给结论/请求**:先说要对方做什么或最重要的信息,再补背景。别让人读到第三段才明白意图。
3. **正文分点**:超过两个要点就用清单;每点一行,带必要的"谁/何时/链接"。
4. **明确的下一步**:谁、做什么、截止时间。含糊的"尽快"换成具体日期。
5. **结尾**:一句礼貌收束 + 署名。

## 语气分寸(按对象调)

- **对上级/客户**:正式、简洁、给选项而非只抛问题(例:"建议 A 或 B,倾向 A,因为…,你看?")。
- **对平级/协作**:友好直接,省略过度客套。
- **跨文化/英文**:更显性地说明上下文与期望;避免缩写与本地俚语。

## 常见场景骨架

- **请求**:背景一句 → 明确请求 → 截止与原因 → 感谢。
- **拒绝/推迟**:先共情/肯定 → 明确无法/延后 → 给替代方案或新时间 → 保持关系。
- **跟进催办**(对方未回复):轻提上次邮件 → 重申请求与截止 → 降低对方成本(给默认选项)。
- **道歉/纠错**:直接认错、不找借口 → 已采取/将采取的补救 → 防止再发生的措施。
- **冷启动(初次联系)**:你是谁/为何找他 → 对他的价值(而非你的需求)→ 一个极小的下一步。

## 自查清单

- [ ] 主题行能让对方一眼判断是否要立即处理?
- [ ] 第一句是否就给了结论或请求?
- [ ] 要对方做的事是否唯一、明确、带截止?
- [ ] 是否删掉了所有不影响理解的废话?
- [ ] 语气是否匹配收件人与场景?

## 英文邮件常用句式

- 开场:"I'm writing to…" / "Following up on…" / "Quick question on…"
- 请求:"Could you please… by <date>?" / "Would you be able to…?"
- 收尾:"Thanks in advance." / "Let me know if anything's unclear." / "Happy to discuss."
