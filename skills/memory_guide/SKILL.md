# memory_guide —— 用好本平台的原生持久记忆

本平台**已内置**跨会话持久记忆,不需要额外的记忆 CLI。本指南讲清"何时记、记什么、
怎么取",让 agent 把记忆用对、用稳。底层能力:

- `memory.remember` —— 写入一条长期记忆(事实/偏好/情景)。
- `memory.recall` —— 按语义检索相关记忆。
- **任务开始自动召回**:每轮任务前会自动取回与当前输入相关的记忆并注入上下文,
  无需手动调用(这一步是自动的)。

## 何时"记住"(memory.remember)

- 主人**显式说"记住…"**:最高优先级,直接记。
- **耐久的偏好**:口味、风格、习惯、工具选择(例:"汇报喜欢先给结论""默认用 DeepSeek")。
- **稳定的事实**:身份、关系、长期目标、关键约束(例:"在做外贸""周报每周五交")。
- 不要记:一次性的临时信息、能从文件/检索现取的内容、含密码密钥的敏感串。

## 记的时候带好元信息

- **来源**:`user`(主人明说,可信度高)vs `agent`(自己推断,需谨慎)。
- **重要性**:越重要分越高;低分项会被定期遗忘(记忆要新陈代谢,不是只进不出)。
- 写法:短、单条、可独立理解。一条记一件事,别把一段话塞成一条。

## 何时"召回"(memory.recall)

- 任务开始的自动召回通常够用;**当你怀疑"主人以前提过相关的事"**时,再显式 recall。
- 检索按"语义相似 × 重要性 × 近用性"综合排序,会优先给出更重要、更近期的记忆。

## 边界与安全

- **无人值守任务(定时任务等)不允许写入长期记忆**,避免错误记忆被持久污染。
- 记忆同样过治理:涉及敏感路径/内容的写入会被拦或需确认。

## 一句话原则

> 召回靠自动、记住靠克制:只把"以后还会用到、且稳定可信"的事写进长期记忆。
