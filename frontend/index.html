安全

管理远程访问令牌、自动执行边界和本地工作区保护。这里的设置决定 Captain 能从哪里访问、写到哪里、遇到风险时是否确认。

访问令牌（远程访问用）
仅手机、Tailscale 或外网访问需要。这里会设置服务端 AGENT_API_TOKEN，并同步保存到本浏览器；本机使用可以留空。
服务端与本浏览器已保存访问令牌
治理档位
建议客户默认使用“平衡”；涉及敏感数据或生产文件时使用“保守”。
安全边界设置
AGENT_WORKSPACE_ROOT 会把文件读写限制在项目工作区内； AUTH_SECRET 用来保护登录态和远程访问。修改 .env 后需要重启服务。 
AGENT_WORKSPACE_ROOT=/Users/luchangjie/Desktop/my agent
AUTH_SECRET=用随机字符串替换，例如运行: python -c "import secrets;print(secrets.token_urlsafe(32))"

模型接入

推荐先配置 OpenRouter 或 DeepSeek；保存后点「测试连接」验证额度、模型名和网络。macOS App 会把 Key 存进 Keychain，服务端不回显明文。

本地优先的 AI Agent 工作台。

Captain

听懂目标 · 自己拆解执行 · 治理可审计


Captain 以安全和数据本地化为核心：你的模型 Key、授权码和项目资料优先留在本机；它能理解模糊目标，拆解计划，使用工具推进任务，并留下可审计记录。
